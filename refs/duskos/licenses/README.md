# Third-party licenses

One of Dusk's primary goals is, through its CC, be able to piggy-back on
existing UNIX code, after modest porting efforts, to maximally benefit from this
wealth while staying true to Dusk's design choices.

All these existing code bases have open source licences and, to make legal
noise inside the code as light as possible, the idea is to include a license
file name in the appropriate source file and then copy the copyright in that
file.
