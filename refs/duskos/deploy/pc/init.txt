Welcome to Dusk OS PC!

This is a [app/gcon] console. Here's a few files you might want to edit:

init.fs init.txt /
text/ed app/ed
io/stream

Quick commands:
graphicsmode
consolemode
reboot

QA commands:
graphicsmode
f<< bench/gr.fs grall
f<< oberon/sys.fs oberon
f<< tests/all.fs

Setup FDC and map to a:
needs fs/core fs/fat drv/pc/fdc
fdc$ init
floppy newfatfs 'A mapfs

Setup XMODEM on COM1 at 115200 bauds for use with ar/tarp:
needs drv/pc/com com/xmodem ar/tarp
com$ com1 xmodem$

Useful XMODEM/tarp commands:
xmodem tar< init.txt
p"" xmodem untar

Update kernel of live system:
needs fs/core xcomp/i386/pc/deploy
bootfs storage install

Setup AHCI drive:
needs drv/pc/ahci io/blk
ahci$ .ahci
0 newahcidrive const mydrive
mydrive enable
\ no geometry autodetect yet, hardcode FAT size
$4000 512 * mydrive to Stream.size

Mount "mydrive" as a: and sync:
needs fs/sh
mydrive newfatfs 'A' mapfs
\ don't sync root files which need to be preserved
walkdst p"a:" walksrc p""
' ONE :> walkdepth if ensurecopyfile. then ; walkdoboth

Deploy Dusk OS a: :
needs xcomp/i386/pc/mkfat
mydrive doit
mydrive newfatfs 'A' mapfs
needs xcomp/i386/pc/deploy
mydrive install
needs fs/sh
walkdst p"a:" walksrc p"" copyall
