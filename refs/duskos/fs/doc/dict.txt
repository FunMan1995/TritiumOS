# System dictionary

This is the list of words provided by the kernel and its boot sequence,
organized by topics.

You should read [doc/usage] first to understand concepts mentioned here.

You should also read [doc/sig] for understanding the documented word signatures.

## Maybe a HAL word?

If the word you're looking for ends with ")" or "," and isn't in here, it might
be a HAL word and is documented in [doc/hal].

## System variables

Some of the words below yield addresses in the SYSVARS area [doc/data], some of
them are regular variables defined in [xcomp/boot.fs], but functionally, they're
all the same. Those words yield an address to the cells containing the
associated value. All those values can be written to at run time, but some are
dangerous to change.

COMPILING    Whether the system is currently compiling a word
CURALLOC     Pointer to the current allocator [doc/usage/mem]
SYSALLOC     System allocator [doc/usage/mem]
PREVRESERVE  Value of "HERE" at the time of the last "reserve" call
SYSDICT      Pointer to system dictionary's latest entry
FINDSTR      Pointer to string last used for findentry
[rcnt]       Current "R level" which is changed when compiling RS-related words
             during compilation [doc/usage/to]
FINDCOMPILER Used by "compiling" find selector to select behavior.
             See [doc/usage/word].
INPTR        Input stream pointer
INSZ         Input stream buffer size in bytes
NEXTIN<      Pointer to ( -- ?a u ) word for input stream rotation
             [doc/usage/io]
CURWORD      Address of last read word (with "word" word). Is a string.
NEXTWORD     Contains the "next word override": When nonzero, the next "word"
             call will yield (and clear NEXTWORD) this word instead of getting
             it from the input stream.
PSORIGIN     Address where PS begins and is reinitialized at "abort"
PSSZ         Size of PS in bytes
RSORIGIN     Address where RS begins and is reinitialized at "quit"
SYSOFF       Offset of next dynamic SYSVARS free slot [doc/data]
HBANKIDX     Current "HAL number bank" index [doc/hal]
HBANK        HAL number bank [doc/hal]
RTYPE        Address for the "rtype ( a u -- )" word
CONSOLETYPE  What RTYPE resets to on "quit"
SCRYING      Global flag controlled by "scry" [doc/usage/word]
ABORTPTR     Word where "abort" points [doc/usage/flow]
QUITHOOK     Called by "quit" right before it calls MAINLOOP [doc/usage/flow]
MAINLOOP     What we end up calling during "quit" [doc/usage/flow]
echoin       Controls input stream echo [doc/usage/io]

Some of those variables above have a HAL operand:

  curalloc) inptr) scrying) insz) rtype)

Those values are indirect values depending on CURALLOC [doc/usage/mem]:

HERE       The value of "here"
HEREMAX    Upper bound for "here"
NEWHERE    "OOM recovery" word pointer ( -- a u )

n,@ ( ... n -- a )
  Replaces a series of "n" calls to ",", except that it reserves the "here"
  memory for those writes beforehand, guaranteeing contiguous memory. Also,
  calls "alignhere" before writing. Then, yield "a" like allot@ does.

move ( src dst u -- )
  Copy u 32-bit units from address src to address dst, moving upwards.
  Register A contains the "dst" address following the last written byte.

cmove ( src dst u -- )
  Like "move", but for 8-bit units. However, "cmove" is "smart", that is, if
  src, dst and u are divisible by 4, "move" is used instead, making it faster.

Dusk's core contains the words:

## I/O

in<         -- c     Read next character from system input source.
in<#        -- c     Like in<, but aborts on EOF.
emit        c --     Emit character to system output destination.
nl>         --       Emit CR then LF.
spc>        --       Emit SPC.
rtype       a u --   Emit characters in range [a, a+u].
stype       s --     Emit all characters in s.
."          "x" --   *I* Compiles: "x" stype
abort"      "x" --   *IC* Compiles: ."x" abort
?abort"     "x" --   *IC* Compiles: if abort"x" then
word        -- s     Try to read a word and error out if EOF is reached.
wordorquote -- s     Read either a word or a quote from input. [doc/usage/io]
\           --       Skip input stream until end of line (LF is the mark).
(           --       Skip input stream until " ) " is read.
console!    xt --    Set both RTYPE and CONSOLETYPE to xt

stepback ( -- )
  Go back one character in the input stream. Next "in<" call will re-yield the
  same character. To avoid memory corruption, this should never be called more
  than once for a given "in<" call.

peekback ( -- c )
  Yield the character that was yielded by the last in< call. This can't go past
  the "single stepback" rule, so if called after a stepback, 0 is yielded.

toword? ( -- f )
  Advance input stream to next non-whitespace character then yield f=1. If EOF
  is reached, yield f=0. If inptr already points to a non-whitespace, f=1 and we
  don't advance.

eol? ( -- f )
  If "peekback" yields LF, exit immediately with f=1. Otherwise, consume the
  input stream until either a non-whitespace, LF or EOF is encountered. f=1 if
  LF or EOF was encountered. Otherwise, f=0. When eol? stops on a word boundary,
  it calls "stepback" before exiting.

  Additionally, whenever a '\' character is read, discard it, discard the
  following character, then continue looping.

  See [doc/usage/io] for more details about how this word is used.

See also [io/stream].

## Parsing, formatting and interpreting

parse ( s -- n? f )
  Try to parse string s as a number. f=1 and n exists if parsing was successful.

parsedec ( a u -- n? f )
  Parse range "a u" as decimal.

parsechar ( a u -- n? f )
  Parse range "a u" as a character.

parsehex ( a u -- n? f )
  Parse range "a u", *without* the "$" prefix", as a hexadecimal.

formatdec ( n -- a u )
  Format number n to decimal into static buffer then yield its range.

formatdecu ( n -- a u )
  Like "formatdec", but unsigned.

formathex ( n -- a u )
  Format number n to 32-bit hex into static buffer then yield its range.

formathex2 ( n -- a u )
  Format number n to 16-bit hex into static buffer then yield its range.

formathex1 ( n -- a u )
  Format number n to 8-bit hex into static buffer then yield its range.

. .x .x2 .x1 ( n -- )
  Call one of the "formatXXX" words on "n" and call rtype.

run1 ( -- )
  Accumulate a word from input stream (that is, call "word") and then run that
  word according to the general interpretation logic, that is:

  1. If it's a number literal, put it on PS.
  2. Otherwise, try to find it in the dictionary.
  3. If found, execute. Otherwise, "word not found" error.

n< ( -- n )
  Repeatedly call "run1" until a single number is placed on PS. If more than a
  single number is placed on PS, abort with "n< overflow".

map< ( "wordname" -- )
  Find "wordname" in sysdict, then run n< on the rest of the line and call the
  found word on each number found. Interpret only. Example usages:

  map< 2* 1 2 3
  . . . \ prints "642"

  create foo map< c, 3 'f' ( comments work! ) 'o' \
    \ full line comments like these work too
    'o'
  foo stype \ prints "foo"

interpret ( -- )
  Call "run1" as long a "in<" doesn't yield EOF.

exec[] ( xt a u -- )
  Execute "xt" with range "a u" as an input stream. Previous input stream is
  restored after "w" returns.

interpret[] ( a u -- )
  Interpret the range of characters "a u" as Forth source code.

## Compiling

Compiling words operate on a higher plane: they write native code to "here",
which can then be executed to have the desired effect. Words from the HAL
[doc/hal] are omitted from the list below but are of course very useful on the
subject of compiling.

[          --       *I* Stop compiling. The following words will be interpreted.
]          --       Begin compiling. The following words will be compiled.
:          "x" --   Create entry x and begin compiling.
:>         -- xt    Like ":", but don't add and entry to dictionary and push
                    execution token to PS.
:realias   --       Compile a word while at the same time "realias"ing the word
                    it shadows to this new word.
:~         --       Create an anonymous word and begin compiling.
;          --       *I* Compile a return from call and then stop compiling.
~          --       Reference to the latest anonymous word. See [usage/word]
code       "x" --   Create entry with name from input stream in sysdict.
code>      -- xt    Like ":>", but for "code".
litn       n --     Compile a literal with value n.
compile    "x" --   *I* Find word x and compile a compilation of a call to it.
[rcompile]  "x" --  *I* Find word x and compile a call to it. Can be used to
                    compile immediate words instead of executing them.
[compile] "x" --    *I* Like [rcompile], but select the "compiling" behavior.
compile]   --       Begin compiling as if we called ":", but without the
                    dictionary entry part. That is: pushlr, ]
compsel    --       Set FINDCOMPILER to 1
immediate  --       Make last added entry into an immediate entry.
create     "x" --   Create a new entry named "x" of type "cell".
                    Resulting data is always aligned to 32-bit.
variable   "x" --   Equivalent to "create 0 ,".
value      n "x" -- See [doc/usage/to]
to         --       *I* See [doc/usage/to]
const      n "x" -- Create a new constant named "x" of value n.
adder      n "x" -- Create a word that adds "n" to PS top. All adders are *A*.
does>      n --     Compile a word that binds "n" to the contents following this
                    very word.
getset,             See [doc/usage/to]
alias      "x y" -- See [doc/usage/word]
entryalias e "y" -- Like "alias", but target entry is supplied as "e" instead of
                    being looked up.
@alias     a "x" -- Create word "x" that calls 4b address contained at "a".
realias    xt t --  Make target word "t" into an alias to "xt".

?scryentry ( e -- ?n f )
  Try scrying entry "e". f=1 on success and n=scrutable value. Otherwise, f=0
  and n is absent.

scryentry# ( e -- n )
  Call ?scryentry and abort with "inscrutable!" if f=0.

scry ( "x" -- n )
  Scry word "x". See [doc/usage/word].

scryfind# ( str -- n )
  Find scrutable word "str" and yield its scrutable value.
  Aborts with "inscutable!" error when word is inscrutable.
  Aborts with "word not found" if word doesn't exist.

?scry, ( n -- )
  Compile a scrying check that conditionally yields "n".

compiling ( compxt runxt "name" -- )
  Create a "findselector" word that yield "compxt" when COMPILING is true and
  "runxt" otherwise. See [doc/usage/word].

inline ( xt "name" -- )
  With "xt" being a compiler word, call it to compile that behavior once, then
  call "compiling" with "compw" being "w" and "runw" being the newly compiled
  word.

inline, ( xt "name" "cname" -- )
  Like "inline", but also records the compiler word as "cname". Example:

  :> PSP) @+, ; inline, drop drop,

bind> ( n xt -- xt )
  Compiles code that pushes "n" to PS then calls "xt", then yields the XT of
  that code.

bind ( n xt "x" -- )
  Like "bind>", but compile that code into a word named "x" instead.

sysvar ( "hal" "const" -- )
sysalias ( "hal" "const" "alias" -- )
  Create dynamic sysvars as described in [doc/data].

consts "..." --
  Reads input stream's rest of line to create multiple constants. Each pair of
  words yields a "const". The first element, ran with "run1" and expected to
  have a ( -- n ) signature, is the value. The second element is the name.
  Example:

    consts 42 foo 54 bar

enum "..." --
  Same as "consts", but with implicit values. Those values are a counter
  starting at 0 and incrementing by 1 each time. Example:

  enum zero one two three
