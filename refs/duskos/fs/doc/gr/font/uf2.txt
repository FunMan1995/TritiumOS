# UF2 font

UF2 is like [gr/font/uf1], but with a dynamic width and height, with a maximum
size of 16x16.

## File format

Every UF2 file is $2100 bytes long and contains $100 glyphs. The first $100
bytes are 8-bit widths, in pixels. We use the maximum values in there to
determine the font's width.

The following $2000 bytes are glyph data in a sequence of 4 ICN images of 8
bytes each. See [gr/font/uf1] for ICN description. Those 4 ICN images are in
this order:

  0 2
  1 3

## API

loaduf2 ( path -- font )
  Open and read "path" containing a UF2 font in memory, yielding a [gr/font]
  structure.
