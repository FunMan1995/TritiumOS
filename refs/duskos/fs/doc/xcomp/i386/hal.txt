dropf,
  A simple "lods," does the trick...

@+, ( operand -- )
  If we target RSP, we generate a "pop" instruction. If we target PSP, we
  generate a "lods".

-@, ( operand -- )
  If we target RSP, we generate a "push" instruction. Unlike "+@,", we can't
  have a STOS shortcut here.
